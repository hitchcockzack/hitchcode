# Hitchcode Website — Agent Contract

Read `HITCHCODE_PRD.md` before making site changes. Its positioning, content-integrity requirements, stage gates, and visual language are authoritative. The work is a custom digital showroom for owner-led operations-heavy businesses, NOT an AI SaaS landing page.

Nonnegotiables:
1. Never fabricate proof, client names, metrics, testimonials or team size. Use `[VERIFY]` for factual copy requiring owner review.
2. Do not clone or copy Basement Studio code/graphics. Study its creative engineering; build original artifacts and a unique visual vocabulary.
3. The signature idea is `Blueprint → Working System`, an aligned technical schematic that becomes an actual interactive demo.
4. No rows of generic rounded service cards, glassmorphism, blobs, generic SaaS templates or AI buzzword copy. Make composition intentional and varied.
5. Preserve existing functionality unless approved. Work on a branch, no deploy without approval.
6. Preview at desktop and mobile widths with screenshots, and actually inspect them.
7. GSAP/SVG/CSS are first-choice animation tools; 3D only when materially useful. Respect reduced motion, keyboard, mobile, performance.
8. Build by the PRD's gates. Show three real HTML hero explorations before committing to a full build. Report artifacts and open decisions.

Primary CTA: `Discuss your operation`. Hero candidate: `You built the business. We engineer what runs it.`
